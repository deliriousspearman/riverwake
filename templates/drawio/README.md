# draw.io templates for network diagrams

Network diagrams in the site's style (the Hardline Classic theme: navy panels, square corners, 2px
outlines, Chakra Petch headings, JetBrains Mono names and addresses). Open them in
[draw.io](https://app.diagrams.net).

| File | Layout |
|---|---|
| `codex-network-zones.drawio` | A box per zone, hosts as cards |
| `codex-network-lanes.drawio` | One column per trust level, least trusted on the left |
| `codex-network-bands.drawio` | Trust levels as bands, top to bottom; narrow, so it stays readable in a lesson |
| `codex-network-hub.drawio` | The firewall in the middle, every zone connected to it |
| `codex-network-icons.drawio` | Device symbols instead of cards, tinted zones |
| `codex-network-icons-os.drawio` | Icons with an OS badge on each host, VMs inside their hypervisor |
| `codex-network-attack.drawio` | Network in grey; only the attack path and its hosts in colour |
| `codex-network-library.xml` | The shapes for all of them (File → Open Library from → Device) |

Each template has a **New diagram** page (the layout's empty zones, title and legend) and an
**Example** page (the same small office network in every layout).

How to use them, and how to export a diagram for a lesson (as `<name>.drawio.svg`, which lessons show
as part of the page), is in the site guide: **Content → Network diagrams**
(`docs/guide/02-content/diagrams.md`). Labels are plain text, not draw.io's formatted (HTML) text:
draw.io exports those as SVG text, which the site accepts; formatted labels export as HTML, which it
refuses (`scripts/drawio-svg.mjs`).

**Fonts.** The templates use the site's fonts (Chakra Petch, Figtree and JetBrains Mono), which
draw.io loads from Google Fonts while online. Without internet access, generate the templates with
`--no-font-source` and install the fonts in `fonts/` on each editor's computer (the TTF files, with
their SIL Open Font Licences); draw.io then uses the installed ones.

The files are generated by `generate.mjs` from one description of each layout (run
`node templates/drawio/generate.mjs templates/drawio`): change the layouts or colours there rather
than editing the files by hand. These files aren't published with the site.

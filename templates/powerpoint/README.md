# PowerPoint template for course slide decks

Slides in the site's style (the Hardline Classic theme, as in the draw.io templates and the lesson
videos: navy background, lime highlights, square panels with 2px outlines, Chakra Petch headings,
Figtree text and JetBrains Mono for code), 16:9.

| File | What it is |
|---|---|
| `codex-slides.potx` | The PowerPoint template: opening it starts a new deck |
| `codex-slides.pptx` | The same deck, for LibreOffice Impress, Keynote and Google Slides, which don't open `.potx` |

Both have one slide master with twelve layouts (Title, Section, Title and content, Two columns,
Three cards, Terminal, Picture, Key point, Quiz, Summary, Title only, Blank), the site's colours
and fonts as the theme (so PowerPoint's colour picker, new shapes, lines and tables are in the
site's style), and an example slide for each layout with speaker notes on using it.

How to use it is in the site guide: **Content → Slide decks** (`docs/guide/02-content/slide-decks.md`).

**Fonts.** The fonts aren't in the files: editors install them from `templates/drawio/fonts/` (TTF,
with their SIL Open Font Licences). Without them PowerPoint substitutes others.

**Changing it.** The files are generated by `generate.mjs` (no dependencies: it writes the
PresentationML and the zip itself), so change the layouts, colours or example slides there and run

```sh
node templates/powerpoint/generate.mjs templates/powerpoint [previews-dir]
```

With a previews folder it also writes an SVG of each example slide and layout and warns about
example text that looks too long for its box. That's an estimate: open the result in PowerPoint
or LibreOffice too. The output is byte-for-byte the same for the same input, and
`tests/powerpoint.test.mjs` fails if the committed files are out of date or a package part is
missing. These files aren't published with the site.

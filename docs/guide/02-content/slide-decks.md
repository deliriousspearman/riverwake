To teach a course in a room or on a call, make its slides from the Codex PowerPoint template, so they match the site and the lesson videos: navy background, lime highlights, square panels, Chakra Petch headings and JetBrains Mono for code.

## Get the template

The template is in the project, under [`templates/powerpoint/`](https://gitlab.example.com/group/codex/-/tree/main/templates/powerpoint). Open the file in GitLab, then **Download**:

| File | Open it in |
|---|---|
| `codex-slides.potx` | PowerPoint. Opening it starts a new, untitled deck, so the template stays as it is. |
| `codex-slides.pptx` | LibreOffice Impress, Keynote or Google Slides (**File → Import slides**, or upload it to Drive and open it), which can't open `.potx` files. Save your deck under a new name. |

**Install the fonts first:** Chakra Petch, Figtree and JetBrains Mono, from [`templates/drawio/fonts/`](https://gitlab.example.com/group/codex/-/tree/main/templates/drawio/fonts) (the same ones the draw.io templates use; double-click each `.ttf` file, then **Install**). Without them, PowerPoint shows other fonts and the text no longer fits as designed. Anyone presenting your deck on another computer needs them too, or present from a PDF.

## The layouts

The deck starts with one example slide for each layout, with notes on using it. Keep the ones you need and delete the rest. Add slides with **Home → New Slide** (the arrow shows the layouts), and change a slide's layout with **Home → Layout**.

| Layout | Use it for |
|---|---|
| Title | The first slide: course name, lesson title, what learners will be able to do, lesson number and length |
| Section | A change of topic, numbered like the course's sections |
| Title and content | The everyday slide: a title and three to five points |
| Two columns | Comparisons: before and after, attack and defence, Windows and Linux |
| Three cards | Three parts of one idea, three steps or three options |
| Terminal | A command and its output, with what to look for beside it |
| Picture | A diagram or screenshot with a caption |
| Key point | One sentence to remember |
| Quiz | A question with four answers, like the lessons' quizzes |
| Summary | Takeaways, and the next lesson |
| Title only | Anything else: a diagram drawn with shapes, or a table |
| Blank | Only the footer |

Every layout but Title, Section and Key point has a small line above the title (the eyebrow) for the lesson or topic. Leave it empty if you don't need it: an empty box doesn't show when presenting. The footer (logo and slide number) is part of the layouts, so you don't add it.

## Writing slides

- **One idea per slide**, said in the title. The points underneath back it up, a line each.
- **Detail goes in the speaker notes** (under the slide in PowerPoint), not on the slide. The lesson itself has the full text.
- Write for defenders, as in the lessons: how it works, what it looks like in the logs and on the network, and how to stop it.
- **Commands:** paste with **Paste as text only** (Ctrl+Shift+V) so they keep the terminal's font. Colour the prompt lime and the line that matters orange or red. Keep it to a dozen lines.
- **Colours:** the template's colours are in PowerPoint's colour picker, in the same order as on the site: lime, blue, orange, red, purple and teal. Use lime for what to look at, red for danger and orange for warnings.
- **Shapes and tables** you add start in the site's style: a navy panel with an outline, grey lines with an arrow, and tables with a lighter header row. The "Title only" example has host cards to copy for small network diagrams.
- **Diagrams:** for a network, start from a [draw.io template](diagrams.md) and insert it on a Picture slide (in draw.io, **File → Export as → PNG** at 200% zoom, or SVG).
- **Quizzes:** put the answer in the notes. To reveal it, duplicate the slide and outline the right answer in lime.
- Use documentation addresses (`192.0.2.x`, `198.51.100.x`, `203.0.113.x`) and `.example` domains, never real ones.

## Sharing a deck with learners

To offer the slides on the lesson, save them as a PDF (**File → Export → PDF**, or **Save as** PDF) and add it to the lesson's downloads (see [Images, downloads and video](images-downloads-video.md)). Slide decks themselves (`.pptx`) can't be uploaded to the site. Keep the `.pptx` wherever your team keeps its working files.

## Changing the template

The template is generated by `templates/powerpoint/generate.mjs`, like the draw.io templates: to change a layout or a colour, a developer changes it there and runs it again (see `templates/powerpoint/README.md`). Changes made to the downloaded file only affect your own copy.
